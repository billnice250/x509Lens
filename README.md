# X509 Lens

X509 Lens is a native certificate and cryptographic-object viewer for macOS,
Windows, and Linux.

Download the latest installers and application packages from
[GitHub Releases](https://github.com/billnice250/x509Lens/releases).

X509 Lens opens certificate files locally and does not install certificates
into the operating system trust store.

## Supported platforms

- macOS
- Windows x64 and ARM64
- Linux x64 and ARM64

## Privacy

Files are opened locally. Network verification is performed only when the
corresponding online verification feature is enabled.
